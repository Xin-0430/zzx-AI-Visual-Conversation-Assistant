## 一、产品简介

AI-VCA（AI Visual Conversation Assistant）是一款**基于浏览器的多模态 AI 视觉对话助手**。它通过整合摄像头视觉理解、语音交互和大模型推理，让用户能够像与真人助手交流一样，让 AI 看到、听到并理解现实世界。

**核心理念：** 从"文本聊天"升级为"环境感知"——用户打开摄像头即可让 AI 理解当前场景，通过语音或文字与 AI 自然对话。

## 二、痛点分析

### 2.1 现有 AI 产品的局限

| 痛点 | 描述 |
|------|------|
| **纯文本局限** | 主流 AI 仍以纯文本对话为主，无法直接理解用户的物理环境 |
| **多模态门槛高** | 整合视觉、语音的 AI 产品要么价格昂贵，要么需要复杂的硬件配置 |
| **成本不可控** | 多模态 API 调用成本高昂，持续视频分析费用难以预估 |
| **接入复杂** | 传统 AI 应用需要注册、下载、配置环境，上手成本高 |
| **场景单一** | 大部分 AI 工具仅面向通用聊天，缺乏垂直场景深度优化 |

### 2.2 目标用户痛点

- **视障用户：** 需要实时了解周围环境，但缺少免费、便捷的视觉辅助工具
- **儿童家长：** 希望 AI 陪伴孩子认知世界，但担心成本和安全问题
- **老年人：** 需要 AI 帮忙识别药品、阅读说明书，但操作复杂的 APP 门槛太高
- **普通用户：** 查东西要打字、拍照、上传太麻烦，想要一句话"帮我看看"

## 三、为什么选择 AI-VCA

### 3.1 核心优势

| 维度 | AI-VCA | 其他产品 |
|------|--------|---------|
| **部署门槛** | 零安装，打开浏览器即可使用 | 需要下载 APP 或安装依赖 |
| **交互方式** | 视觉 + 语音 + 文字 多模态融合 | 通常仅支持文本或单一模态 |
| **使用成本** | 低至 0.3 美元/月（低频用户） | 流式视频分析成本不可控 |
| **架构设计** | 事件驱动触发，按需调用 AI | 持续推理，资源浪费严重 |
| **服务商切换** | 支持 OpenAI / Gemini / 离线模拟 | 通常绑定单一厂商 |
| **隐私保护** | Web Speech API 本地语音识别，不上传语音数据 | 云端语音识别，数据外传 |
| **轻量化** | Vanilla JS，无外部依赖 | 通常依赖重型框架 |

### 3.2 产品差异化

- **事件驱动 AI 架构：** 不做持续推理，只在用户交互时触发，大幅降低成本
- **可插拔 Provider：** 统一接口，支持 OpenAI、Gemini、MockProvider，业务与 AI 厂商解耦
- **场景化 Prompt 系统：** 四种场景模式（视障辅助/儿童教育/老人陪伴/懒人模式），每种 300-500 字精细调校
- **成本可视化：** 实时追踪 Token 消耗和费用，用户对成本一目了然

## 五、产品闭环

### 5.1 用户价值闭环

用户打开场景 -> 摄像头捕获画面 -> 语音/文字提问 -> AI 融合理解（图像+语音+场景提示词） -> 自然语言回答+语音播报 -> 用户获得即时反馈 -> 信任建立 -> 持续使用 -> 成本可见 -> 放心高频使用 -> 依赖加深

### 5.2 技术交互闭环

用户输入层：摄像头帧 + 语音识别 + 文字输入 -> App.js 主控制器（帧采样+压缩+防重复锁） -> AI Provider 抽象层（OpenAI / Gemini / Mock） -> 输出层（聊天显示 + TTS 播报 + 费用统计）

### 5.3 商业闭环

低门槛试用（离线 Mock） -> 用户体验真实价值 -> 配置个人 API Key（自带 Key，零平台成本） -> 成本透明可控 -> 同预算下更多使用频次 -> 高频使用 -> 场景依赖 -> 口碑传播 -> 用户增长

### 6.3 技术约束

- **纯前端：** 不依赖任何后端服务器，所有逻辑在浏览器中完成
- **零依赖：** 使用原生 JavaScript（Vanilla JS），无 React/Vue 等框架依赖
- **浏览器 API：** 依赖 WebRTC（getUserMedia）和 Web Speech API
- **AI 接口：** 前端直连 OpenAI / Gemini API，无需代理层

### 6.4 非功能需求

| 需求 | 指标 |
|------|------|
| **首屏加载** | 小于 1s（纯静态资源） |
| **帧采样响应** | 小于 500ms |
| **AI 推理耗时** | 取决于 API 响应（典型 1-3s） |
| **月成本（低频）** | 约 0.3 美元 |
| **月成本（高频）** | 约 6.0 美元 |
| **兼容浏览器** | Chrome / Edge（完整支持），Firefox / Safari（部分支持） |

### 6.5 架构决策记录（PDR）

| 决策 | 选择 | 理由 |
|------|------|------|
| 前端框架 | Vanilla JS | 减少依赖，更轻量，3 天开发更高效 |
| 语音引擎 | Web Speech API（免费） | 零成本、零延迟、隐私性好 |
| AI 架构 | Provider 抽象层 | 可插拔后端，统一分析接口 |
| 图像策略 | JPEG 压缩 + 分辨率限制 | 传输成本下降 90% |
| 触发策略 | 事件驱动（非流式） | 成本下降 60%+ |
| 模型选型 | GPT-4o-mini（default） | 比 GPT-4o 便宜 16 倍 |

## 八、使用场景

### 8.1 视障辅助

用户：打开摄像头对准前方
AI：您前方是一条人行道，右侧有台阶（约 20cm 高），前方 3 米处有行人正在靠近。左侧停有一辆白色轿车。建议沿盲道行走，注意前方台阶。

### 8.2 儿童教育

用户：打开摄像头对准宠物狗
AI：这是一只金毛犬！它的毛发是金色的，看起来很柔软。金毛犬性格温顺友善，是非常受欢迎的家庭犬种。小朋友，你知道金毛犬最喜欢做什么吗？它喜欢游泳！

### 8.3 老人陪伴

用户：打开摄像头对准药盒
AI：这是复方丹参滴丸，主要用于缓解心绞痛。用法是每次 10 粒，舌下含服。建议您在服用前先咨询医生。当前药品剩余充足，但请注意查看包装上的有效期。

### 8.4 懒人模式

用户：帮我看看冰箱里有什么
AI：冰箱里有：鸡蛋（剩 6 个）、番茄（2 个，略软建议尽快食用）、牛奶（还剩半盒）、西兰花（1 颗）。建议您今天做番茄炒蛋！

## 九、快速开始

### 9.1 立即使用

1. 打开 index.html（推荐 Chrome / Edge）
2. 点击摄像头按钮，授权摄像头和麦克风
3. 选择场景模式（通用 / 视障辅助 / 儿童教育 / 老人陪伴 / 懒人模式）
4. 点击麦克风按钮说话，或直接在输入框打字
5. AI 会结合画面内容回答你，同时语音播报

### 9.2 配置 AI 服务

OpenAI（推荐）：
- 在设置中选择 OpenAI
- 填入 API Key（sk-...）
- 默认模型：gpt-4o-mini（最省成本）

Google Gemini：
- 在设置中选择 Gemini
- 填入 API Key（AIza...）

离线模拟模式：
- 无需配置，开箱即用
- 返回模拟响应，用于体验交互流程

### 9.3 成本控制建议

低频使用（约 60 次/月）：打开默认设置即可，月成本约 0.3 美元
中度使用（约 300 次/月）：建议帧采样 3，质量 50%，月成本约 1.8 美元
高频使用（约 1000 次/月）：建议帧采样 5，质量 30%，月成本约 6.0 美元

## 十二、成本控制

### 12.1 控制系统

| 控制项 | 默认值 | 可选值 | 效果 |
|--------|-------|-------|------|
| 帧采样间隔 | 3 帧 | 1/3/5/10 | 减少 60-90% 调用量 |
| 图片质量 | 50% | 30%/50%/70%/90% | 传输量降低 90% |
| 图片最大宽度 | 640px | 320/640/1280 | 传输量按比例降低 |
| AI 模型 | gpt-4o-mini | gpt-4o/gpt-4o-mini | 成本差 16 倍 |
| 图像细节 | detail:low | low/high | 按 85x85 tile 计费 |

### 12.2 成本估算

| 使用强度 | 月调用量 | 月成本 |
|---------|---------|-------|
| 低频用户 | 约 60 次 | 约 0.3 美元 |
| 中频用户 | 约 300 次 | 约 1.8 美元 |
| 高频用户 | 约 1000 次 | 约 6.0 美元 |

### 12.3 成本设计哲学

事件驱动大于流式处理：不做持续视频分析，只在用户触发时调用 AI
端侧优先大于云端依赖：语音识别用 Web Speech API（免费），图像在端侧压缩
单次合并大于多轮拆分：图像+语音+提示词一次合并调用，减少 API 次数
