# PR #4: Visual Memory System

## 功能描述
每次视觉对话自动将摄像头快照保存为侧边栏缩略图，形成可视化时间线。核心能力：
- 自动保存：每次成功 AI 分析后保存画面快照
- 一键回顾：点击缩略图触发 AI 重新分析该画面
- FIFO 淘汰：最多保存 12 条，超出自动移除最旧记录
- 一键清空：设置面板中的清空按钮

## 实现思路
- Base64 data URL 存储在内存数组（非 localStorage，隐私优先）
- MAX_MEMORY=12 上限，FIFO 淘汰策略
- renderMemory() 使用 DocumentFragment 批量 DOM 插入
- 缩略图点击回调触发 sendQuery 进行 AI 分析
- 每次成功的 processQuery 后更新记忆

## 测试方式
1. 打开摄像头，发送查询，验证侧边栏出现缩略图
2. 再发送查询，验证第二个缩略图出现
3. 点击缩略图，验证触发 AI 重新分析
4. 打开设置，点击清空记忆，验证缩略图清除
5. 连续发送 13+ 查询，验证只保留 12 条

## 依赖声明
无外部依赖。纯 DOM 操作。
