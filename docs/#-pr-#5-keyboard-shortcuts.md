# PR #5: Keyboard Shortcuts

## 功能描述
为键盘用户增加快捷键支持：
- Ctrl+Enter / Cmd+Enter: 发送当前消息
- Escape: 关闭设置弹窗
- 数字键 1-5: 直接切换到对应场景模式

## 实现思路
- 单一 document 级 keydown 监听器
- 短路条件避免干扰文本输入（仅在非输入状态响应数字键）
- Escape 检查弹窗可见性再关闭
- 数字键通过 DOM click() 派发到模式按钮

## 测试方式
1. 输入消息，按 Ctrl+Enter → 消息发送
2. 打开设置弹窗，按 Escape → 弹窗关闭
3. 依次按数字键 1-5 → 对应场景模式激活
4. 在输入框中输入数字 → 不触发模式切换

## 依赖声明
无外部依赖。纯 DOM 事件处理。
